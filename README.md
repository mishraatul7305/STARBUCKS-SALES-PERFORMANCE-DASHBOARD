# ☕ STARBUCKS SALES ANALYTICS DASHBOARD

## 📌 Project Overview
This Power BI dashboard provides an interactive analysis of Starbucks sales data, helping users understand sales trends, profit, quantity sold, and overall business performance.

## 📊 Dashboard Features
- KPI Cards (Average Sales, Total Sales, Maximum Profit)
- Sales by Quantity Analysis
- Interactive Line & Column Charts
- Dynamic Filters & Slicers
- Starbucks-Themed Dashboard Design

## 🛠 Tools Used
- Power BI
- Microsoft Excel
- Power Query
- DAX

## 📈 Key Insights
- Analyze overall sales performance
- Identify high-selling quantities
- Monitor profit trends
- Compare sales across different categories
